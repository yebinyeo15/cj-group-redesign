# CJ GROUP | Website Redesign

CJ그룹의 브랜드 가치와 다양한 사업 영역을 시각적으로 전달하기 위해 제작한 **기업 웹사이트 리디자인 프로젝트**입니다.

기존 기업 웹사이트 클론코딩의 HTML/CSS 구조를 기반으로 CJ그룹의 브랜드 아이덴티티에 맞게 콘텐츠와 비주얼을 재구성했습니다.

## 01. Project Overview

| 항목        | 내용                                  |
| ----------- | ------------------------------------- |
| Project     | CJ GROUP Website Redesign             |
| Type        | Corporate Website Redesign            |
| Role        | UI Design · Web Publishing            |
| Design Tool | Figma                                 |
| Development | HTML5 · CSS3 · JavaScript · Swiper.js |
| Responsive  | Desktop 중심 구현                     |

## 02. Project Concept

**Inspiring a New World**

CJ그룹의 핵심 사업인 식품, 바이오, 물류·신유통, 엔터테인먼트·미디어를 중심으로 글로벌 생활문화기업의 이미지를 표현했습니다.

다양한 사업 분야를 하나의 웹사이트에서 직관적으로 탐색할 수 있도록 콘텐츠를 구성하고, 대형 비주얼과 간결한 타이포그래피를 활용해 브랜드 메시지를 강조했습니다.

## 03. Key Features

**Hero Visual**

- 4개의 메인 비주얼 슬라이드
- Swiper.js 기반 이전/다음 슬라이드 전환
- 슬라이드별 이미지 및 브랜드 메시지 구성

**Business**

- CJ그룹의 주요 사업 영역 4개 소개
- 이미지와 텍스트를 활용한 카드형 레이아웃
- 이미지 확대 및 버튼 호버 인터랙션

**Innovation**

- 지속가능한 혁신 및 스마트 물류 혁신 소개
- 2열 이미지 카드 레이아웃
- 마우스 호버에 따른 시각적 변화

**CJ Newsroom**

- K-푸드, K-컬처, 라이프스타일, 지속가능경영 콘텐츠
- 2×2 이미지 그리드 구성

**About CJ**

- CJ그룹 기업 소개
- 기업소개, 지속가능경영, 인재채용 바로가기 카드

## 04. Tech Stack

- **HTML5:** 시맨틱 마크업 및 페이지 구조
- **CSS3:** 레이아웃, 타이포그래피, 호버 인터랙션
- **JavaScript:** 슬라이드 및 사용자 인터랙션
- **Swiper.js:** 메인 비주얼 슬라이더
- **Figma:** UI 디자인 및 레이아웃 설계
- **VS Code:** 개발 환경

## 06. Design Direction

- **Visual:** 대형 이미지와 간결한 기업형 레이아웃
- **Color:** CJ 브랜드에서 영감을 받은 블루, 오렌지, 네이비
- **Typography:** Pretendard, Noto Sans KR, Titillium Web
- **Interaction:** 슬라이드 전환 및 카드 호버 효과

## 07. Project Notes

본 프로젝트는 개인 학습 및 포트폴리오 제작을 목적으로 진행한 비공식 리디자인 작업입니다.

CJ그룹의 공식 웹사이트가 아니며, 사용된 브랜드명과 로고 및 관련 이미지의 권리는 각 권리자에게 있습니다.

기존 클론코딩 구조를 기반으로 디자인과 콘텐츠를 재구성한 프로젝트입니다.
